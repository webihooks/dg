# Borzo Delivery Integration for DeeGeeCard.com

## Overview
This integration adds Borzo delivery functionality to DeeGeeCard.com, allowing customers to get real-time delivery quotes and track their orders.

## Directory Structure
- `/config` - Borzo configuration files
- `/classes` - Core Borzo API classes
- `/api` - AJAX endpoints for frontend integration
- `/webhook` - Webhook handler for Borzo callbacks
- `/assets` - CSS and JavaScript files
- `/templates` - Page templates for Borzo features
- `/logs` - Borzo-specific log files
- `/tests` - Test scripts
